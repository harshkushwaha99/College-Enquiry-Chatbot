# 🎓 College Enquiry Chatbot

A smart web-based College Enquiry Chatbot developed using **Python Flask, SQLite, HTML and CSS**.

The application helps students get information about college courses, duration, fees and other college-related queries through a simple chatbot interface.

---


---

## 🚀 Features

- 🏠 Modern College Home Page
- 👤 Student Registration and Login
- 📚 Course Information
- 🤖 Smart College Enquiry Chatbot
- 💬 Student Suggestions
- 📩 Contact Form
- 🔐 Admin Login
- 📊 Admin Dashboard
- 👨‍🎓 Manage Students
- 📚 Manage Courses
- 🤖 Manage Chatbot Questions and Answers
- 💬 Manage Student Suggestions
- 📩 Manage Contact Messages
- 🚪 Secure Logout
- ❌ Custom 404 and 500 Error Pages

## 🛠️ Technologies Used

### Backend

- Python

- SQLite

### Security

- Werkzeug Password Hashing
